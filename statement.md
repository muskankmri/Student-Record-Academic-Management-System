# Student Record and Academic Management System

## Problem Statement

Managing student academic records manually can be time-consuming and may lead to errors while handling student details, courses, marks, attendance, and performance information.

This project provides a Python-based console application to organize and manage student academic records in a structured manner. It allows users to add, search, update, and delete student records, manage courses, record marks and attendance, analyze performance, and perform basic data operations.

## Scope

The system covers:

- Student record management
- Course management and student-course assignment
- Marks and grade management
- Attendance recording and percentage calculation
- Academic performance analysis
- Student searching and sorting
- Duplicate removal and kth-smallest data operations
- Input validation and error handling

The project is designed as a console-based academic management system and focuses on core Python programming and data-structure concepts.

## Target Users

- Students learning Python and data structures
- Faculty or instructors demonstrating academic management concepts
- Users who need a simple console-based student record system

## High-Level Features

1. Student Management – Add, display, search, update, and delete student records.
2. Course Management – Add courses, display courses, assign courses, and view student courses.
3. Marks Management – Enter marks, display marks, calculate grades, and evaluate performance.
4. Attendance Management – Record attendance, calculate attendance percentages, and identify low attendance.
5. Performance Analysis – Calculate class average, identify topper and lowest performer, and display grade distribution.
6. Search and Data Operations – Search students, perform selection sort, remove duplicates, and find the kth-smallest value.

## Project Objective

The main objective is to develop a modular Python application that demonstrates the practical use of functions, data structures, searching, sorting, input validation, and academic data processing while providing a simple system for managing student records.
