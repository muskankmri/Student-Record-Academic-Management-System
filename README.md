Student Record and Academic Management System



A Python console-based application for managing student academic records, courses, marks, attendance, academic performance, and basic search/data operations.



## Features



- Student management: add, display, search, update, and delete

- Course management: add, display, assign, and view student courses

- Marks management: enter marks, display grades, and calculate performance

- Attendance management: record attendance and calculate percentages

- Performance analysis: class average, topper, lowest performer, grade distribution

- Search and data operations: search, selection sort, duplicate removal, kth-smallest search

- Input validation and error handling



## Technologies and Concepts



- Python 3

- Functions and modular programming

- Lists, dictionaries, tuples, and sets

- Loops and conditional statements

- Searching and selection sort

- Input validation and error handling

- Git and GitHub
